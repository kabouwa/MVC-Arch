# MVC-Arch

Just a test project — learning the MVC (Model-View-Controller) design pattern in plain PHP, before starting Laravel.

Not a real/production project, just here to learn and practice.

## Structure
- `Controllers/` — handle requests, coordinate Models and Views
- `Models/` — data and business logic
- `Views/` — templates / presentation
- `Services/` — helper/service classes
- `config/` — configuration
- `public/` — entry point (index.php)

## Stack
- PHP (vanilla, no framework)

## Notes
This repo is for learning purposes only. Expect messy code and experiments.
